# Distribuição do Disco 1: situação

**Situação em 01/11/2026: download em preparação. Nenhum arquivo jogável foi publicado e não há data.**

A primeira análise mostrou que a versão traduzida dependia de arquivos do patch inglês. A versão definitiva do Disco 1, aprovada em 01/11/2026, parte da base japonesa e deixa de usar esses arquivos, com uma exceção decidida pelo projeto: a fonte. Essa versão ainda não foi publicada.

## O que mudou na versão definitiva

| item | antes | agora |
|---|---|---|
| Fonte | `font.pgf` (FTT-NewRodin Pro DB), vinda do patch inglês | Mantida, idêntica à da versão anterior, para preservar a aparência |
| Executável | Baseado no do patch inglês | Baseado no japonês, com alterações próprias do projeto |
| Imagens de instalação | Do patch inglês | As originais japonesas |
| Dados de boca das vozes | 96 tabelas do patch inglês, sem dados de 33 falas | As tabelas originais japonesas, completas |
| Textos do `envpsp.dat` | 596 textos vindos da base inglesa | 595 eram iguais ao japonês; 1 título foi romanizado pelo projeto |

Fora a fonte, nenhum arquivo da versão definitiva é idêntico a um arquivo exclusivo da versão inglesa. Scripts, imagens traduzidas, vídeos e textos de interface são os mesmos da versão anterior, salvo uma quebra de linha ajustada.

## O que ainda falta

1. Definir o formato de distribuição e confirmar que ele respeita os direitos sobre o jogo e sobre a fonte.
2. Testar em outros ambientes: Windows, Android e PSP real não foram testados.

Este documento é uma análise técnica, não um parecer jurídico.
