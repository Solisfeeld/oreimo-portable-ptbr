# Histórico de versões

## Não lançado

* Download direto da ISO definitiva do Disco 1 pelo Internet Archive, nos botões do site e no README; Disco 2 continua indisponível.
* Perguntas frequentes e documentação pública atualizadas para distinguir a ISO disponível de um patch independente, que não existe.
* Site e README com a capa oficial do jogo, galeria de capturas reais e textos voltados aos jogadores.
* Limitações conhecidas e detalhes técnicos movidos para `docs/`.
* Compatibilidade e avisos sobre as imagens movidos do site e do README para [docs/COMPATIBILIDADE.md](docs/COMPATIBILIDADE.md) e [docs/CREDITOS_E_AVISOS.md](docs/CREDITOS_E_AVISOS.md).
* Versão definitiva do Disco 1 aprovada, construída sobre a base japonesa.
* Site e README simplificados para os jogadores; créditos e avisos detalhados concentrados em `docs/`.
* Site com uma única área de download; saíram a seção sobre a tradução, a faixa de números e o estado dos discos.

## v0.1.0-disc1 (pré-versão)

Primeira versão pública do repositório.

* Disco 1: tradução, testes técnicos e conferência manual no PPSSPP concluídos.
* Ferramentas independentes para ler ISO, GPDA, GIM, scripts e `envpsp.dat`, com testes próprios.
* Automação isolada do PPSSPP com roteiro de exemplo.
* Documentação dos formatos do jogo.
* `referencia/`: código de trabalho, só para estudo.
* Site do projeto em GitHub Pages.
* Licenças: MIT para o código próprio e CC BY 4.0 para a documentação própria, com exceções em [docs/LICENCAS.md](docs/LICENCAS.md).
* Análise do patch público em [docs/PATCH.md](docs/PATCH.md).
* Disco 2 não iniciado.

Esta versão não inclui ISO, patch, instalador nem os textos da tradução. Notas em
[docs/notas-versao/v0.1.0-disc1.md](docs/notas-versao/v0.1.0-disc1.md).
